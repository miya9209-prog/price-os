# MISHARP 가격책정 OS

신상품의 원가를 기준으로 적용판매가, 할인적용 실결제가, 1장당 공헌이익, 총공헌이익, 공헌이익률, A~E 등급과 손익 방어선을 계산하는 미샵 내부용 Streamlit 프로그램입니다.

## V1 포함 기능

- 상품원가 입력
- 상품원가 부가세 포함/별도 선택
- 목표 원가배수 1.5~5.0배, 0.1배 단위 선택 / 0.5배 간격 상시 눈금 표시
- 광고비율 0~15%, 1% 단위 선택 / 5% 간격 상시 눈금 표시
- 할인·쿠폰율 0~50%, 1% 단위 선택 / 5% 간격 상시 눈금 표시
- 세금평균 4%, 수수료 3.5%, 포장비 1% 기본값
- 적용판매가 자동 생성 및 직접 판매가 입력
- 800원/900원/100원 단위 가격 끝자리 선택
- 경쟁사 평균가격 수동 입력
- 1장당 공헌이익 / 공헌이익률 / 예상수량 총공헌이익
- A/B/C/D/E 공헌이익 등급
- 손익분기 광고비율
- 이론상 손익분기 할인율
- 할인율 × 광고비율 가격 시뮬레이션
- V1 규칙 기반 WHY 진단
- 모바일 대응 / 상단 가로 메뉴 / 좌측 메뉴 없음

## 계산 기준

개발계획서에는 부가세, 세금평균 4%, 수수료 3.5%, 포장비 1%, 광고비, 할인·쿠폰을 반영하도록 정의되어 있지만 각 항목의 정확한 회계 산식은 별도로 명시되어 있지 않습니다. 따라서 V1은 다음 **구현 가정**을 사용합니다.

1. 소비자 판매가는 부가세 포함 가격으로 봅니다.
2. 원가가 부가세 포함이면 원가에서 매입부가세를 분리합니다.
3. 원가가 부가세 별도이면 10% 매입부가세를 추가합니다.
4. 매출부가세에서 매입부가세를 상계한 금액을 추정부가세 부담으로 계산합니다.
5. 할인·쿠폰 적용 후 실결제가를 만든 뒤 세금평균·수수료·포장비·광고비 비율을 적용합니다.
6. 할인금액은 실결제가에 이미 반영되므로 비용으로 한 번 더 차감하지 않습니다.

> 실제 미샵 회계/정산 기준이 다르면 `pricing_engine.py` 한 곳만 수정하면 전체 화면에 반영됩니다.

## 공헌이익 등급 기본 규칙

- A: 공헌이익률 25% 이상
- B: 18% 이상 25% 미만
- C: 12% 이상 18% 미만
- D: 5% 이상 12% 미만
- E: 5% 미만

이 등급 구간은 V1 운영 기준이며 실제 데이터 검증 후 조정할 수 있습니다.

## GitHub 업로드

이 폴더 전체를 새 GitHub Private repository의 루트에 업로드합니다.

```text
misharp-pricing-os
```

## Streamlit Cloud 배포

1. Streamlit Community Cloud 로그인
2. `Create app` 또는 `New app`
3. GitHub repository로 `misharp-pricing-os` 선택
4. Branch: `main`
5. Main file path: `app.py`
6. Deploy

V1은 외부 API 비밀키가 없으므로 Secrets 입력 없이 바로 실행됩니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

테스트:

```bash
pytest -q
```

## V1.2 판매 안전선

- 메인 KPI에서 이론상 손익분기 광고비/쿠폰율을 분리했습니다.
- 공헌이익률 20% 이상을 유지하는 **광고비 권장 최대치**를 자동 계산합니다.
- 공헌이익률 20% 이상을 유지하는 **할인 권장 최대치**를 자동 계산합니다.
- 이론상 손익분기점은 보조 정보로 접어서 표시합니다.
- 할인 입력 범위는 기존 계획대로 최대 50%이며, 실제 손익분기 할인율이 그보다 높으면 `50% 초과 가능`으로 표시합니다.


## V1.3 슬라이더 가독성 개선

- 목표 원가배수 슬라이더 위에 `1.5 / 2.0 / 2.5 / 3.0 / 3.5 / 4.0 / 4.5 / 5.0` 기준값을 항상 표시합니다.
- 실제 목표 원가배수 선택은 기존처럼 0.1배 단위를 유지합니다.
- 광고비율은 0~15% 범위에서 1% 단위로 선택하며 `0 / 5 / 10 / 15` 눈금을 항상 표시합니다.
- 할인·쿠폰율은 0~50% 범위에서 1% 단위로 선택하며 `0 / 5 / 10 ... / 50` 눈금을 항상 표시합니다.
- 눈금은 모바일에서도 한 화면에서 판단하기 쉽도록 작은 고정 숫자로 표시합니다.
